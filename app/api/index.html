Built for safety by default

Every mode enforces its own validation. Live and DEX execution require explicit confirmation.

📄 Paper

Default mode. No real money moves. Synthesises fills from live prices so you can validate a strategy end-to-end.

🧪 Testnet

Routes orders to Binance Futures Testnet. Requires API credentials. Never touches real funds.

💸 Live

Real Binance Futures. Requires ENABLE_LIVE_TRADING=true, confirmation string, and valid credentials. Gated at startup.

🔗 DEX (Hyperliquid)

Public market data is read-only. Signed orders require an explicit preview/approval flow through the admin panel.

What's inside

📊

Pluggable strategies

EMA crossover, MACD, Bollinger, RSI mean-reversion, and the original ensemble. Drop a Python file in app/strategy/user_strategies/ to add your own.

🔒

Approval gate

DEX orders go through preview → approve → place. The bot never auto-approves; the wallet owner does.

📱

Mobile & web dashboard

Read-only endpoints power a phone-friendly PWA. Live status, recent signals, open positions, balances, and trade history.

📡

Signals to Telegram

Every signal can be posted to a Telegram chat with a built-in deduplicator so you don't get spammed.

🐳

Container-ready

Single Docker image, multi-version CI, health checks, smoke tests, and a rollback playbook.

🛡️

Risk guardrails

Per-trade risk, daily loss cap, max positions, leverage cap, exposure ceiling, and consecutive-loss circuit breaker.
